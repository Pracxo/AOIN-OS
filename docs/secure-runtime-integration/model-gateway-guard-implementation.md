# Model Gateway Guard Implementation

The model-gateway guard binds current authorization, AION-231 component binding, parent secure-runtime session, parent capability plan, parent runtime guard, parent kill-switch state, gateway session, request envelope, provider manifest, model manifest, capability profile, context budget, token budget, routing, fallback, retry, circuit breaker, cost estimate, latency estimate, and structured schema when required.

Allowed outcome is only `allow_reference_simulation`. The guard never returns provider-call, network-egress, tool-call, function-call, or production-execution permission.
