# Capability Runtime Architecture

AION-234 authorizes AION-235 to implement a sandboxed deterministic capability runtime. The future runtime may execute only closed, schema-validated, deterministic, in-memory reference operations selected explicitly by the operator and bound through policy, risk, guardrails, existing approval evidence, zero-external-effect budgets, and kill-switch controls.

AION-234 does not implement this runtime.
