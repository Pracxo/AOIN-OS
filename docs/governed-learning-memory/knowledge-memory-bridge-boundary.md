# Knowledge Memory Bridge Boundary

The bridge between Knowledge Intelligence and Cognitive Architecture is advisory until separately authorized. Knowledge Intelligence produces reviewable candidates and evidence posture. Cognitive Architecture owns persistent memory mechanics. Governed Learning and Memory Integration may plan how a candidate could project into semantic, episodic, procedural, or belief-candidate memory records, but AION-222 may not write those records.

Projection planning must preserve provenance, uncertainty, dissent, conflict state, and rollback references. It must not create factual truth automatically.
