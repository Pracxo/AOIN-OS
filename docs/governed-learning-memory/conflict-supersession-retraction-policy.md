# Conflict, Supersession, and Retraction Policy

The program treats conflict, supersession, and retraction as first-class states. A conflict candidate blocks automatic promotion. Supersession requires lineage preservation. Retraction requires the original support and decision evidence to remain reviewable.

AION-222 may detect and report these states in a dry-run transaction plan. It may not erase prior evidence or mutate existing knowledge or belief state.
