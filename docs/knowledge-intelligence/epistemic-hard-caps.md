# Epistemic Hard Caps

Hard caps apply in this exact order: broken_source_registry_or_graph_integrity, applicable_retraction, applicable_supersession_without_current_support, scope_mismatch, insufficient_explicit_scope, unresolved_material_opposition, zero_independent_evidence_groups, one_independent_evidence_group, only_unknown_or_community_unverified_evidence, missing_citation_coverage, incomplete_provenance, stale_evidence.

Each cap records a cap ID, reason code, pre-cap confidence, post-cap confidence, optional forced status, applied flag, and fingerprint. No cap can increase confidence and no later cap can remove a stricter earlier cap.
