# Epistemic Assessment Integrity

AION-211 integrity auditing validates score weights, scorecard version, confidence bounds, quantization, confidence band mapping, hard-cap order, non-increasing caps, known reason codes, fingerprints, batch counts, no source-body leakage, no absolute-truth field, no automatic decision, no knowledge or belief state, no persistent write, and no runtime effect.

Findings contain only safe IDs, reason codes, bounded counts, and redacted summaries.
