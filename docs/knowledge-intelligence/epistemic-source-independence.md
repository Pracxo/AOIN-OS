# Epistemic Source Independence

AION-211 counts independent evidence by source-registry lineage group. Duplicate content, canonical URL duplicates, exact URL duplicates, repeated citations, repeated provenance, and mirror records cannot raise independent-source counts.

An independence group can contribute at most once per role. A group that contains both support and opposition is role-ambiguous and counts toward neither side. Context evidence is preserved as context and contributes no support or opposition score.
