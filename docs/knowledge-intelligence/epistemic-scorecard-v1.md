# Epistemic Scorecard v1

The AION-211 scorecard is deterministic, transparent, versioned as `aion-epistemic-scorecard/v1`, and free of model calls, hidden weights, learned weights, random values, and source-count-only ranking.

Exact role-score weights are: reference_resolution 0.10, evidence_coverage 0.10, citation_coverage 0.10, provenance_completeness 0.10, source_independence 0.25, source_quality_metadata 0.10, valid_time_applicability 0.08, jurisdiction_applicability 0.06, version_applicability 0.06, freshness 0.05. The exact sum is 1.00.

Thresholds are fixed: minimum independent support groups 2, minimum independent opposition groups 2, supported threshold 0.55, contradicted threshold 0.55, mixed threshold 0.35, dominance margin 0.20, and abstention confidence threshold 0.70.
