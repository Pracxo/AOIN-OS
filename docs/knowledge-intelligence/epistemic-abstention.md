# Epistemic Abstention

Explicit abstention is required for integrity failure, insufficient scope, scope mismatch, unknown, insufficient_evidence, mixed, stale, superseded, retracted, confidence below 0.70, unresolved material contradiction, or any hard cap that forces abstention.

Even when abstention is false, AION-211 still creates no automatic acceptance, automatic rejection, knowledge promotion, belief mutation, persistent write, runtime action, approval, PR, merge, or deployment.
