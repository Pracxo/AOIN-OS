# Epistemic Source Quality Metadata

AION-211 uses the immutable v1 source-quality metadata factor map: primary_authoritative=1.00, official_standard=1.00, official_government=0.90, peer_reviewed=0.85, vendor_primary=0.70, institutional_primary=0.70, reputable_secondary=0.60, community_unverified=0.35, unknown=0.25, and disallowed=0.00.

These factors describe source metadata only. Source class alone cannot establish support, bypass independence, bypass citation or provenance checks, bypass scope mismatch, bypass retraction, bypass unresolved contradiction, or override broken integrity.
