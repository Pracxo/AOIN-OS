# 0181: Deterministic Verified Knowledge Candidate Memory and Engagement-Learning Candidate Plane

## Status

Accepted for AION-217 implementation pending AION-218 formal closeout.

## Context

AION-216-KI-0007 authorizes AION-217 to implement a deterministic in-memory verified-knowledge candidate memory and engagement-learning candidate plane. The authorization keeps persistent verified-knowledge writes, automatic promotion, cognitive-memory writes, belief mutation, engagement factual effects, public-network calls, tool execution, runtime registration, and deployment at zero.

## Decision

Implement immutable Pydantic contracts and pure in-memory services for integrated lineage, support and refutation eligibility, confidence inheritance, confidence non-amplification, candidate versioning, supersession, retraction, expiry, explicit revalidation, copy-on-write repositories, deterministic snapshots, bounded exact queries, fixture replay, integrity audits, redacted evidence, operator-review items, bounded engagement signals, and non-factual engagement-learning candidates.

## Consequences

A verified-knowledge candidate remains reviewable evidence. Eligibility is not factual truth, approval, promotion, cognitive memory, or belief mutation. Engagement may create operator-review learning candidates but cannot change factual confidence, policy, model weights, source independence, or knowledge state. AION-218 must evaluate the implementation and close AION-216-KI-0007 if appropriate.
