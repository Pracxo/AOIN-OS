# ADR 0192: Controlled Operator-Invoked Local Continual-Learning Pilot Composition and Execution

## Status

Accepted for AION-228 implementation pending AION-229 final evaluation and closeout.

## Context

AION-227 authorized exactly one controlled local continual-learning pilot under AION-227-GLM-0004. The authorization requires explicit operator invocation, three bounded cycles, existing controlled public DNS and pinned HTTPS composition, verified-candidate review, approval-bound promotion planning, dual-approved temporary local persistence, read-only cross-cycle context, in-memory shadow adaptation, contradiction abstention, rollback, cleanup, and redacted evidence.

## Decision

Implement AION-228 as a composition layer instead of a production learning runtime. The new source surface is limited to governed continual-learning contracts, explicit cycle orchestration, component bindings, integrity, evidence, and an uninstalled operator runner. CI uses deterministic in-memory research backends. The live pilot uses existing controlled DNS and HTTPS backends and commits only redacted evidence.

## Consequences

AION-228 provides a completed pilot result, not durable production learning. AION-227-GLM-0004 remains active, unconsumed, unexpired, and non-reusable until AION-229 performs final evaluation and closeout. Background learning, scheduled learning, source discovery, crawlers, automatic approval, automatic promotion, retained stores, production memory writes, production policy mutation, belief mutation, source mutation, Git mutation, and model training remain disabled.
