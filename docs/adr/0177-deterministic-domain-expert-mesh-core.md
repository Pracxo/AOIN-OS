# 0177: Deterministic Domain Expert Mesh Core

Status: Accepted

Date: 2026-07-25

## Context

AION-212-KI-0005 authorizes AION-213 to implement a deterministic, evidence-bound, in-memory domain expert mesh while keeping runtime activation and persistent mesh writes disabled. The authorized scope is `deterministic-domain-taxonomy-expert-profile-routing-independent-analysis-deliberation-disagreement-synthesis-abstention-core`.

## Decision

Implement the mesh as immutable contracts plus pure in-memory services under Knowledge Intelligence. The mesh uses explicit taxonomy tags, computational profiles, deterministic routing, independent panels, evidence-bound reports, critiques, disagreement preservation, bounded synthesis, confidence non-amplification, high-stakes abstention, integrity audits, synthetic fixture replay, exact queries, and operator-review evidence.

## Consequences

The mesh does not impersonate human experts, claim professional credentials, call model providers, execute tools, access a network, create evidence, decide truth, accept or reject claims, promote knowledge, mutate beliefs, create API or CLI runtime surfaces, write persistent mesh state, deploy, train model weights, create a v0.2 tag, or alter aion-v0.1.0. AION-214 remains required for formal closeout.
