# 0209: Post-RC1 v0.3 Development Baseline and Adaptive Intelligence Programme Authorization

## Status
Accepted

## Context
AION-244 completed the v0.2 release-qualification programme and published `aion-v0.2.0-rc.1` as a prerelease with 24 assets. The active development line must move away from the released RC package version without modifying the tag, release, retained assets, or candidate source commit.

## Decision
AION-245 establishes `0.3.0.dev0` as the Brain API and SDK development version, charters `AION-ADAPTIVE-INTELLIGENCE-001`, and creates `AION-245-AI-0001` as the sole active Adaptive Intelligence implementation authorization.

`AION-245-AI-0001` authorizes only AION-246: a controlled provider-neutral external-cognition gateway foundation using contracts, manifests, envelopes, routing policies, budgets, structured-output validation, trust, redaction, deterministic fixtures, replay, circuit breakers, observability, audit, and evidence controls.

## Consequences
The programme is authorized but not implemented. Live provider calls, public network access, DNS resolution, provider credentials, provider tokens, persistent learning, real tools, connectors, autonomous loops, production runtime, source mutation, Git mutation, deployment, publication, and model-weight training remain disabled.

AION-247 is the next formal evaluation task. AION-247 through AION-260 remain planned and unauthorized unless a future task explicitly authorizes them.
