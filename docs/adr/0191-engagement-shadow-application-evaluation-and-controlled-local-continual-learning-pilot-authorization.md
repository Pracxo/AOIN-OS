# ADR 0191: Engagement Shadow Application Evaluation and Controlled Local Continual-Learning Pilot Authorization

## Status
Accepted

## Context
AION-226 implemented the deterministic operator-approved non-factual engagement-learning shadow application. AION-227 evaluated that plane through AION-GLMPE-003 and repaired the one genuine resource-budget enforcement defect through PR #143.

## Decision
AION-225-GLM-0003 is closed as consumed by AION-226. Because AION-GLMPE-003 passed all 28 hard-gated scenarios, AION-227-GLM-0004 is created as the sole active GLM implementation authorization for AION-228.

## Consequences
AION-228 may implement one controlled, operator-invoked local continual-learning pilot with explicit public HTTPS research, verified knowledge, temporary isolated persistence and in-memory shadow adaptation. AION-227 creates no AION-228 runtime source, no network session, no store, no overlay, no persistent state, no production policy mutation, no memory write, no belief mutation, no model training and no v0.2 tag or release.
