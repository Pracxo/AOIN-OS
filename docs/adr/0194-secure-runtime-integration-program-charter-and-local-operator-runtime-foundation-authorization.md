# ADR 0194: Secure Runtime Integration Program Charter and Local Operator Runtime Foundation Authorization

## Status

Accepted

## Context

AION-229 completed the Governed Learning and Memory Program through
`AION-GLMPE-004`. The Cognitive Architecture, Knowledge Intelligence, Governed
Learning and Memory, and governed self-improvement programs now provide an
implemented intelligence plane, but AION still needs a secure local operational
control plane before model, connector, module, production, deployment, or v0.2
release work can progress.

## Decision

Create `AION-SECURE-RUNTIME-INTEGRATION-001` as a separate program. Create
`AION-230-SRI-0001` as the sole active Secure Runtime Integration
implementation authorization for AION-231 only.

AION-231 is authorized to implement a controlled, authenticated,
operator-invoked, local secure runtime foundation that composes offline
identity verification, RequestIdentity, ActorContext, replay validation,
session lifecycle, policy, risk, guardrails, approval evidence, side-effect
budgets, runtime guard, kill switch, audit, observability, and deterministic
fixture replay through a side-effect-free boundary.

AION-232 is the formal AION-231 operator evaluation and next-authorization
decision task. AION-233 through AION-238 remain planned and unauthorized.

## Consequences

The Secure Runtime Integration Program becomes the active program, but secure
runtime implementation source does not exist yet. AION-230 creates governance,
docs, ledgers, examples, static console data, tests, and gates only.

Production authentication runtime, public auth endpoints, external identity
providers, credentials, tokens, networks, model providers, connectors, tools,
shell commands, subprocesses, browser automation, modules, production writes,
production memory, production policy, beliefs, GLM live execution, source
rewrite, Git mutation, deployment, model training, production exposure, v0.2
tags, and v0.2 releases remain disabled or absent.
