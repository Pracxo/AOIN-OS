# Adaptive Intelligence Evaluation Model

Every Adaptive Intelligence stage requires independent evaluation before the next stage can proceed.

AION-246 must be evaluated by AION-247 before any live-provider pilot is considered. AION-247 may authorize only one controlled operator-invoked live-provider pilot if the deterministic foundation passes all checks. Later stages follow the same pattern: implementation, independent evaluation, then a narrow successor authorization decision.

Evaluation requirements:

- exact authorization and parent-program lineage
- exact source scope
- exact approved capability list
- exact prohibited capability list
- exact resource limits
- deterministic fixtures only for AION-246
- no provider calls
- no network
- no credential or token reads
- no persistent memory writes
- no real tool or connector execution
- no autonomous background loops
- no production deployment
- complete audit and decision lineage
