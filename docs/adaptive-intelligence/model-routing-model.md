AION-246 may define provider-neutral routing contracts for model and capability selection.

Approved concepts include provider manifests, model manifests, model capability records, request envelopes, response envelopes, message normalization, structured-output schemas, routing policies, declared context budgets, declared output budgets, declared cost budgets, latency budgets, retry policies, circuit breakers, trust classification, uncertainty projection, provider-error normalization, redaction policies, fingerprints, deterministic fixtures, replay, audit, observability, operator review records, and static console evidence.

The routing model remains a contract foundation. `adaptive_routing_runtime_enabled=false`, `actual_model_provider_call_enabled=false`, and `model_output_triggered_execution_enabled=false`.
