# Adaptive Intelligence Architecture Roadmap

AION-245 starts the v0.3 development line after the published `aion-v0.2.0-rc.1` prerelease. The roadmap activates intelligence in governed layers and requires independent evaluation before each wider capability.

## Planned Sequence

- AION-245: Post-RC1 baseline reconciliation and Adaptive Intelligence Programme authorization.
- AION-246: Controlled provider-neutral external-cognition gateway foundation.
- AION-247: External-cognition foundation evaluation and live-provider pilot authorization decision.
- AION-248: Operator-invoked controlled live-model provider pilot.
- AION-249: Live-provider pilot evaluation and governed internet-research authorization decision.
- AION-250: Governed public-internet research acquisition runtime.
- AION-251: Research evaluation and verified-knowledge promotion authorization decision.
- AION-252: Verified knowledge consolidation into persistent semantic and episodic memory.
- AION-253: Persistent-memory evaluation and engagement-learning authorization decision.
- AION-254: Outcome, feedback and engagement-learning runtime.
- AION-255: Learning evaluation and domain-expert router authorization decision.
- AION-256: Multi-model domain-expert router, critic and verifier mesh.
- AION-257: Domain-router evaluation and real-tool fabric authorization decision.
- AION-258: Sandboxed real-tool and connector execution runtime.
- AION-259: Integrated adaptive-intelligence pilot and benchmark programme.
- AION-260: Final Adaptive Intelligence Programme evaluation and v0.3 release-candidate authorization decision.

Only AION-246 is authorized by AION-245. AION-247 through AION-260 remain planned and unauthorized.

## Architecture Direction

The target system may eventually route work to external or local reasoning models, perform governed public research, verify claims against provenance-bound evidence, consolidate verified knowledge into semantic and episodic memory, learn from operator feedback, preserve uncertainty and disagreement, select domain experts and critics, execute approved tools inside sandboxes, run bounded plans, and retain complete audit lineage.

These capabilities are staged. AION-245 authorizes only the contract foundation for external cognition. It does not activate model providers, internet research, persistent learning, tools, connectors, autonomous execution, production runtime, publication, or deployment.
