# Epistemic Assessment No-Go

The AION-211 no-go gate rejects runtime registration, persistence, database libraries, tracked state files, network imports, hidden or learned weights, provider calls, absolute-truth booleans, automatic claim decisions, contradiction resolution, knowledge promotion, belief mutation, source mutation, Git mutation, runtime PRs, approval creation, automatic merge, deployment, dependencies, migrations, workflow changes, v0.2 tags, and v0.2 releases.
