# Secure Runtime Integration Scope

AION-230-SRI-0001 authorizes AION-231 only. AION-232 is the required formal
closeout and next-authorization decision task.

AION-231 may implement local, operator-invoked, side-effect-free foundation
composition for:

- offline Ed25519 identity assertion composition
- public-key registry reads
- request identity projection
- ActorContext binding
- persistent replay-protection validation
- ephemeral local operator session lifecycle
- deterministic runtime state machine
- request envelope validation
- capability invocation plans
- policy, risk, guardrail, and approval-evidence binding
- side-effect budget enforcement
- runtime guard decisions
- operator kill switch
- audit projection
- observability snapshots
- runtime health readiness
- deterministic fixture replay
- redacted operator review items

The AION-231 source paths are implemented exactly in the authorized
secure-runtime foundation scope. No AION-232 evaluation result, AION-233
model-gateway authorization, public auth route, provider integration,
connector runtime, tool runtime, module loader, credential store, token store,
production write path, v0.2 tag, or v0.2 release is created.
