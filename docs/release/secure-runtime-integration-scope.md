closeout and next-authorization decision task.

- request envelope validation
- capability invocation plans
- policy, risk, guardrail, and approval-evidence binding
- side-effect budget enforcement
- runtime guard decisions
- operator kill switch

- observability snapshots
- runtime health readiness
- deterministic fixture replay

The scope creates no AION-231 runtime source during AION-230. AION-231 source
paths are recorded only as future scope.
