# Adaptive Intelligence Security Boundary

AION-245 preserves the post-RC1 release boundary and starts v0.3 development without enabling runtime intelligence.

`aion-v0.2.0-rc.1` remains published and unchanged. Stable AION OS v0.2.0 remains unpublished.

The AION-246 external-cognition foundation is authorized for deterministic contract work only. Provider calls, internet research, credentials, tokens, persistent learning, real tools, connectors, autonomous loops, production runtime, deployment, source mutation, Git mutation, automatic merge, and model-weight training remain disabled.
