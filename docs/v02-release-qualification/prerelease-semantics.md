# Prerelease Semantics

AION-244 authorizes a GitHub prerelease only.

- Candidate label: `aion-v0.2.0-rc.1`
- Python package version: `0.2.0rc1`
- Release name: `AION OS v0.2.0-rc.1`
- Stable release: false
- Stable tags: prohibited
- Production deployment: disabled

A stable `0.2.0` release requires a separate source commit, build, evidence set, signatures, and final evaluation.
