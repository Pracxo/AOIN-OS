# AION-243 Candidate Build Report

The final build report is written to committed redacted evidence after the
local runner creates and validates the retained candidate.

The report records candidate source commit, source-tree fingerprint, artifact
fingerprints, retained image ID, SBOM fingerprint, provenance chain head,
checksum manifest fingerprint, qualification public-key fingerprint,
signature-verification count, compatibility result, migration result, retention
state and release boundary counters.

The report never records the absolute retained-candidate path.
